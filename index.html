Canvas Snippet Library

Ready-made banners, callouts, buttons, and page layouts for your Canvas courses. Find one you like, copy its code, and paste it into your page. Everything is in the Mount's colors and built to be readable for every student.

How to use a snippet (about two minutes)
  1. Find the snippet you want below. Click inside its code box (or press the Select code button). All of the code highlights.
  2. Copy it with Ctrl+C (Windows) or Cmd+C (Mac).
  3. Open the Canvas page you want to edit and click Edit. Switch to the HTML view by clicking the </> icon in the bottom right corner (it may say "Switch to raw HTML editor." You don't have to.).
  4. Click where you want the snippet to go, then paste with Ctrl+V (Windows) or Cmd+V (Mac).
  5. Switch back to the regular editor view with the same icon. Click on the placeholder words and type your own.
  6. Save the page, then view it as a student would. Click any buttons or links to make sure they go where you expect.
Good to know: Don't paste into the regular editor view! Make sure you're in the HTML editor. Where you see PASTE-YOUR-LINK-HERE, replace it with a real link (select the text, then use Canvas's link button). The snippets that need a link or a video code are labeled on each card. And if you get stuck, CETL@mtaloy.edu is happy to help.
Want to change colors? Use the Mount palette

Every snippet uses only these colors, which pass accessibility contrast checks in the combinations shown. If you adjust a snippet, stick with these.

Blue #095398 Navy #051d3c Purple #9a52a0 Light blue #24abe2 White #ffffff
  • White text works on blue, navy, and purple.
  • Light blue is for borders and accents only. If text sits on light blue, make the text navy, never white.
  • Use navy or dark gray for paragraph text on white or pale backgrounds.
